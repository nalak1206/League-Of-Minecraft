# 전설 아이템 명세

상점의 전설 아이템은 역할군별 6종, 총 36종입니다. 모든 아이템은 구매·저장·기본 능력치 적용이 가능하며, 고유 효과는 공통 전투 엔진 개발과 함께 순차 연결합니다.

아이템은 실제 인벤토리를 차지하지 않는 가상 장비입니다. `/lol shop`에서 역할군 페이지를 이동해 구매합니다.

## 공통 제한 사항

- 주문력은 저장·합산되지만 챔피언 스킬 공식 전체에는 아직 연결되지 않았습니다.
- 방어구/마법 관통력, 치명타, 스킬 가속, 생명력 흡수, 강인함을 공통 능력치로 통합하는 작업이 남아 있습니다.
- 액티브 아이템의 공통 사용 키와 대상 지정 UI가 아직 없습니다.
- 효과가 `구매·기본 능력치`인 아이템도 상점에서 정상 구매되고 재접속 후 유지됩니다.
- 칠흑의 양날 도끼는 현재 충전된 기본 공격으로만 중첩되며 물리 스킬 피해 연동은 공통 피해 엔진 이후 적용합니다.
