# 현재 작업 인수인계

이 문서는 다른 컴퓨터나 다른 작업자가 가장 먼저 읽는 현황판입니다. 기능을 완료할 때마다 반드시 갱신합니다.

## 현재 기준

- 버전: `0.10.1`
- Minecraft: `26.2`
- Fabric Loader: `0.19.3`
- Fabric API: `0.157.0+26.2`
- Java: `25`
- 기본 브랜치: `main`
- 원격: `https://github.com/nalak1206/League-Of-Minecraft.git`
- 로컬 테스트 프로필: CurseForge `league of minecraft`
- 배포 파일명: `mods/league-of-minecraft.jar`

## 알려진 문제와 기술 부채

- 모드 이름은 `LOL Hyunmin`이지만 파일/패키지/모드 ID 일부가 아직 `darius_skills`입니다.
- 다리우스 초기 코드에 깨진 한글 문자열 흔적이 일부 남아 있습니다.
- 요네는 원본 기반으로 전면 개편됐지만 Minecraft 충돌·순간이동 특성상 Q3, E, R의 장애물 상호작용은 인게임 검증이 필요합니다.
- `CombatEngine`은 현재 전설 아이템 추가 피해만 연결되어 있으며 챔피언 스킬과 고정 피해·관통력은 아직 여러 코드 경로에 흩어져 있습니다.
- 아이템 스킬 가속, 마법 관통력, 강인함, 둔화 저항은 아직 능력치 엔진에 완전히 연결되지 않았습니다.
- 칠흑의 양날 도끼는 충전된 기본 공격으로만 중첩되며 물리 스킬 연동은 공통 피해 엔진 이후 적용합니다.
- `/lol gold add|set` 권한 제한은 Minecraft 26.2 명령 권한 API에 맞춰 다시 넣어야 합니다.
