# 현재 작업 인수인계

이 문서는 다른 컴퓨터나 다른 작업자가 가장 먼저 읽는 현황판입니다. 기능을 완료할 때마다 반드시 갱신합니다.

## 현재 기준

- 버전: `0.11.1`
- Minecraft: `26.2`
- Fabric Loader: `0.19.3`
- Fabric API: `0.157.0+26.2`
- Java: `25`
- 기본 브랜치: `main`
- 원격: `https://github.com/nalak1206/League-Of-Minecraft.git`
- 로컬 테스트 프로필: CurseForge `league of minecraft`
- 배포 파일명: `mods/league-of-minecraft.jar`

## 구현 완료

- 다리우스 P/Q/W/E/R과 God King 테마 VFX 1차
- 요네 P/Q/W/E/R 원본 기반 전면 개편
- 요네 W/R 시전 잠금, 공격 속도 연동, 즉발 Q·Q3 돌진·에어본, W 혼합 피해·보호막
- 요네 E 영체 돌진·피해 기록·고정 피해 복귀, R 정신집중·후방 이동·다중 대상 집결
- 요네 패시브 두 번째 공격 물리/마법 50:50과 스킬별 VFX/SFX
- 요네 검별 패시브 타격, Q 폭풍·Q3 나선, W 180도 참격·동적 보호막, E 육체·영체·표식 VFX 2차
- 요네 R 스크린샷 기반 검은 직사각형·붉은 경계·검붉은 평행 띠·중앙 청회색 검광·도착 반원·진공 집결 VFX 적용, X자 궤적 제외

- 요네 첫 평타·Q 왼손, 두 번째 평타·W 오른손, R 양손 모션 연결

- Z/X/C/V 입력, 챔피언 선택, ADVENTURE/MATCH 모드
- 레벨 1~18, 스킬 랭크와 공통 CC 상태
- 액션바 쿨타임
- 월드별 진행도·골드·아이템 저장
- GUI 상점

- `강철심장`, `벼락폭풍검`, `원칙의 원형낫` 명칭 반영

## 알려진 문제와 기술 부채

- 모드 이름은 `LOL Hyunmin`이지만 파일/패키지/모드 ID 일부가 아직 `darius_skills`입니다.
- 다리우스 초기 코드에 깨진 한글 문자열 흔적이 일부 남아 있습니다.
- 요네는 원본 기반으로 전면 개편됐지만 Minecraft 충돌·순간이동 특성상 Q3, E, R의 장애물 상호작용은 인게임 검증이 필요합니다.
- `CombatEngine`은 현재 요네와 전설 아이템 추가 피해가 연결되어 있으며 다리우스 스킬·고정 피해·관통력은 아직 여러 코드 경로에 흩어져 있습니다.
- 아이템 스킬 가속, 마법 관통력, 강인함, 둔화 저항은 아직 능력치 엔진에 완전히 연결되지 않았습니다.
- 칠흑의 양날 도끼는 충전된 기본 공격으로만 중첩되며 물리 스킬 연동은 공통 피해 엔진 이후 적용합니다.
- `/lol gold add|set` 권한 제한은 Minecraft 26.2 명령 권한 API에 맞춰 다시 넣어야 합니다.
