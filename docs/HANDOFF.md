# 작업 인수인계

다른 컴퓨터나 작업자는 먼저 이 문서와 `ARCHITECTURE.md`, `ITEMS.md`, `CHANGELOG.md`를 읽습니다.

## 현재 기준

- 버전: `0.15.3`
- 브랜치: `main`
- 원격: `https://github.com/nalak1206/League-Of-Minecraft.git`
- 실행 환경: Minecraft 26.2 / Fabric Loader 0.19.3 / Fabric API 0.157.0+26.2 / Java 25
- 배포 파일: CurseForge `league of minecraft/mods/league-of-minecraft.jar`

## 구현된 기반

- 다리우스, 요네, 말파이트 P/Q/W/E/R과 전용 무기·VFX·SFX
- Z/X/C/V 스킬, P 상점, M LoL 인벤토리, B 귀환, Alt 장비/장신구 입력과 액션바 쿨타임
- 공통 CC, 물리/마법 피해, 관통력, 치명타 계산
- 레벨 1~18, 경험치, 스킬 포인트와 스킬 랭크
- 골드, 처치 보상, MATCH 자연 골드, 저장 데이터
- 8페이지 상점 GUI, 시작 아이템·장화·역할군별 전설 아이템
- 6칸 가상 장비 인벤토리와 전설 아이템 36종의 1차 고유 효과
- 전투 수식·Alt 슬롯·아이템별 액티브 쿨타임 JUnit 회귀 테스트
- 블루/레드 팀, 로비/진행 상태, 팀 기지·부활과 아군 피해 차단
- 스코어보드 팀 동기화, 아군 와드 시야와 적 팀 렌즈 감지
- 와드 엔티티 영구 태그 복원, 적 와드 파괴와 10골드 보상
- 사용자 중심 구원과 기사의 맹세 아군 우클릭·영구 결속
- `/lol reset`과 실제 챔피언 변경 시 챔피언 성장 상태 초기화
- 와드는 적의 기본 공격 3회에 파괴되며 남은 체력이 엔티티 태그로 유지됨
- `/lol reset`은 구매 장비·골드·장신구·기사의 맹세 결속·설치 와드까지 초기화
- 투명 와드는 2충전·90초 재충전·동시 활성 2개 제한이며 충전 상태가 저장됨
- MATCH 상점은 아군 기지 반경 12블록에서만 사용 가능
- 챔피언 처치 300G/300XP, 최근 10초 기여 어시스트 150G/150XP
- 말파이트: 8초 비피격 화강암 방패, Q 이동 속도 강탈, W 6초 강화 평타,
  E 광역 마법 피해·공격 속도 저하, R 11블록 돌진·에어본
- 순수 규칙 회귀 테스트 30개 통과

## 0.13.2 GUI와 장비 입력

- 상점은 `P`, LoL 전용 3줄 가상 장비 화면은 `M`으로 엽니다.
- `B`는 진행 중인 MATCH에서 8초 정신 집중 후 자신의 팀 기지로 귀환합니다.
- 이동·피격·기본 공격·스킬 입력·사망·경기 종료 시 취소되며 B를 다시 눌러 직접 취소할 수 있습니다.
- M 화면 첫 줄은 `LEVEL/Q/W/빈칸/E/R/GOLD`, 둘째 줄은 `1~3번/빈칸/4~6번` 구조입니다.
- 첫 줄의 빈칸은 장신구 슬롯이며 M 화면에서 투명 와드/예언자의 렌즈를 전환합니다.
- `Alt+1/2/3/5/6/7`은 둘째 줄의 가상 장비 1~6번, `Alt+4`는 장신구를 사용합니다.
- Alt 조합 사용 후 서버와 클라이언트 모두 핫바 1번을 다시 선택합니다. 챔피언 기본 무기는 실제 핫바 1번에 있습니다.
- 상점의 스킬 랭크가 0이면 방벽, 시작 아이템 페이지 배경은 흰색 판유리로 표시됩니다.

상점 전체 목록과 효과 구현 상태는 `docs/ITEMS.md`를 기준으로 합니다.

## 0.13.0 서비스 개편

- `ChampionDefinition`과 `ChampionRegistry`가 챔피언 공통 생명주기를 담당합니다.
- 다리우스는 상태와 VFX, 요네는 상태와 이동/잠금 서비스를 스킬 본체에서 분리했습니다.
- 아이템 효과는 `CombatEngine`의 공통 챔피언 피해 훅으로 발동합니다.
- 처치 시 원칙의 원형낫이 현재 챔피언의 궁극기 쿨타임을 공통 인터페이스로 환급합니다.

## 0.13.3 안정화

- `CombatMath`는 저항력, 관통력, 스킬 가속의 마인크래프트 비의존 수식을 담당합니다.
- `PerPlayerCooldowns`는 플레이어와 아이템 조합별 액티브 쿨타임을 분리합니다.
- `EquipmentSlotBindings`가 Alt+숫자와 6칸 장비·장신구 매핑의 기준입니다.
- `src/test/java`에 순수 로직 회귀 테스트가 있으며 기능 변경 시 함께 갱신합니다.

## 0.14.0 MATCH 기반

- `/lol match team auto|blue|red|none`으로 팀에 참가하거나 나갑니다.
- 각 팀 기지에서 `/lol match base set blue|red`를 실행한 뒤 `/lol match start`로 시작합니다.
- 경기 시작·재접속·사망 후 부활 때 해당 팀 기지로 이동합니다.
- 경기 중 같은 팀 사이의 플레이어 피해는 차단됩니다.
- 경기 상태는 월드의 `data/league_match.json`에 별도 저장됩니다.

## 0.14.1 귀환

- `RecallSystem`이 서버 틱 기준 160틱 정신 집중과 취소·완료를 관리합니다.
- 귀환 중에는 챔피언 쿨타임 액션바 대신 귀환 남은 시간이 표시됩니다.
- 이동 허용 오차와 남은 시간 계산은 순수 `RecallMath` 및 단위 테스트로 검증합니다.

## 0.14.2 팀 와드 시야

- `MatchScoreboardTeams`가 MATCH 팀과 바닐라 스코어보드 팀을 동기화합니다.
- `lom_blue`, `lom_red`는 아군 투명 개체 표시가 활성화되어 같은 팀 와드를 볼 수 있습니다.
- 와드는 설치자와 설치 당시 팀을 보관하며, MATCH 렌즈는 반경 12블록의 적 와드만 드러냅니다.
- `TeamWardRules`가 Minecraft 비의존 팀 시야 판정을 담당하고 단위 테스트로 검증합니다.

## 0.14.3 와드 생명주기

- 와드 엔티티 태그에 설치자 UUID·소유 팀·절대 만료 시각을 저장합니다.
- `TrinketSystem`이 1초마다 현재 로드된 청크의 미추적 와드를 찾아 팀과 만료 처리를 복원합니다.
- 진행 중인 MATCH에서는 적 팀 와드만 파괴할 수 있고 파괴자에게 10골드를 지급합니다.
- 서버 종료 시 메모리 목록만 비우며, 엔티티와 태그는 월드 저장을 통해 그대로 유지됩니다.

## 0.14.4 서포터 지정 효과

- 구원은 장비 단축키를 누른 사용자의 현재 위치를 중심으로 반경 8블록에 즉시 발동합니다.
- MATCH 팀을 기준으로 아군 플레이어만 회복하고 적 플레이어와 몹만 피해를 받습니다.
- 기사의 맹세를 보유한 플레이어가 아군을 우클릭하면 결속 대상 UUID가 계정 데이터에 저장됩니다.
- MATCH에서는 같은 팀, ADVENTURE에서는 자신을 제외한 다른 플레이어를 결속할 수 있습니다.
- 결속 대상이 같은 차원의 32블록 안에 살아 있을 때만 기존 보호 효과가 활성화됩니다.

## 0.14.5 기사의 맹세 피해 이전

- 결속 대상이 받은 실제 피해의 12%를 되돌리고 가장 가까운 유효 기맹 소유자에게 이전합니다.
- 소유자 체력이 30% 이하이거나, 다른 차원·32블록 밖·비아군이면 이전과 회복이 비활성화됩니다.
- 이전 피해는 방어력·방패·저항 효과를 무시하고 가시 갑옷·밤의 끝자락·스테락·다른 기맹을 연쇄 발동하지 않습니다.
- 결속 대상이 적 플레이어에게 준 실제 피해의 10%만큼 소유자가 회복합니다.
- 이전의 임시 저항 효과와 전투 중 고정 주기 회복은 제거했습니다.

## 0.14.6 아이콘·스킬 포인트 정합성

- 시작 아이템 11종, 장화 16종, 전설 아이템 36종의 아이콘을 확정 목록대로 전면 교체했습니다.
- 여신의 눈물은 투척용 물병, 피바라기는 치유의 화살, 몰락한 왕의 검은 광택이 있는 다이아몬드 검으로 표시됩니다.
- 상점과 M 가상 인벤토리는 모두 `LolShopItem.createIcon()`을 사용해 같은 아이콘을 표시합니다.
- 1~18레벨에서 레벨당 총 스킬 포인트를 정확히 1개로 정규화하며 저장 데이터도 불러올 때 자동 보정합니다.
- 미습득 스킬 입력은 공통 챔피언 입력부에서 차단하고 지정 경고 문구를 액션바에 표시합니다.

## 주의점

- 정식 네임스페이스는 `league_of_minecraft`입니다. `darius_skills`는 0.14.8 이하 챔피언 무기 로드·자동 교체를 위한 호환 등록에만 남겨 둡니다.
- 챔피언 무기는 일반 상점 장비와 별개이며 챔피언 전환 시 정리되어야 합니다.
- 피해 공식 수정은 `CombatEngine`과 챔피언별 고정 피해 경로를 모두 확인해야 합니다.
- 저장 필드를 추가할 때 `LolPlayerDataStore`의 저장과 불러오기를 같이 수정합니다.
